# 舵轮底盘
## vesc和5010电机
有关vesc的使用可以查看官方教程https://blog.csdn.net/gjy_skyblue/category_11126869.html
1. 建议使用CAN1、CAN2，使用大疆A板时注意按照原理图配置CAN的引脚
2. vesctool使用最新版即可(附在soft目录下)，使用USB线连接后，架空(不能碰地)设置电机FOC参数：智能类型\75g\34_02\电池数6\电机极数14\
motor：编码器AS5047(如果发现电机不能低速运动，可能是minerpm默认值太大); app：\id任意\波特率1M\
可以直接在右侧按钮下载已有的配置对比，也可以使用方向键进行电机运动测试
3. 5010电机三条电源线任意连接，连接电调至CAN2和编码器时注意线序(25年r2找硬件定制了分线板，编码器改焊了线序)\
PS：刚开始接手学长调过的底盘时，CAN线是把3pin焊成一坨插到4pin口中，很乱
4. makerx和makerbase电调可以不连编码器进行开环控制，也可以用闭环控制，但需要依照手册连编码器线
5. 光电门引出的三条线：红->5V, 黑/深褐->GND, 黄/白->信号线 
   
## 遥控器和as69通信模块
1. 使用前，需要在h文件和c文件的初始化函数中修改串口号
2. 如果不能进入串口中断回调函数，说明两个as69未配对
3. as69的通道、波特率和地址需要一致，进入中断函数但收不到信息可能是地址不匹配
4. 遥控器上的as69被内部的主控板固定，只能通过上位机软件(asds)修改连接下位机的as69(需要用串口转TTL模块)\
遥控器主控板的代码老学长还在维护github：wtr-joystick-air
